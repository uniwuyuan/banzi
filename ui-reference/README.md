# UI 参考实现

从半字输入法（闭源部分）中抽出的 UI 侧参考代码，**不可直接编译**（依赖项目内其它类），
用于展示布局/动画的实现方式。接口与数据结构见 `../docs/ALT-PAGES-SPEC.md`。

| 文件 | 作用 |
|---|---|
| `AltPages.java` | 统一二级页渲染器：数字页（1:3:1 五等分、九宫格）、符号页、Emoji 页；JSON 驱动、滚动网格、页签栏 |
| `RhythmView.java` | 候选栏空闲时的「律动条」：频谱 + 打字节拍涟漪 + 弹簧动画，无音频时退化为静态点阵 |
| `RhythmBus.java` | 律动数据总线（音频快照 + 按键计数），视图每帧只读 |
| `PrivacyBreathDrawable.java` | 隐匿模式状态提示：⌄ 键暗紫呼吸（L1/L2 不同周期与峰值） |

要点：
- 布局全部用代码计算 + 自绘，不依赖 XML 布局和第三方 UI 库
- 二级页几何与 26 键页逐像素同高：`4 × KEYH`
- 所有尺寸/配色来自设计台 JSON（见 `../design/SCHEMA.md`），改 JSON 即换皮肤
