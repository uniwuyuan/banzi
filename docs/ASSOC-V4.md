# 联想算法 v4（2026-11-09 凌晨研究）

> 结论先说：v4 = **扩大候选池 + 证据门槛**。离线回放 held-out：
> hit@1 2.84%→3.98%，hit@3 5.86%→7.54%，hit@5 7.21%→9.72%，MRR 0.0442→0.0601（相对旧版 +40%/+29%/+35%/+36%）。
> 构建 0.5.44 / versionCode 140，默认启用（`assoc_v4=true`，关掉回退 v3）。

## 一、研究问题

v3 的打分本身还行，但候选池只有「前词学过的接续」。离线回放发现两个硬问题：

1. **16% 的位置压根没有候选**：前词没在历史里出现 → v3 返回空 → 联想栏空着。
2. **个人高频词单独当候选时 recall@5 = 10.8%，比上下文模型（7.0%）还高**。
   说明模型不缺排序，缺的是「候选覆盖」。

## 二、评测协议（可复现）

数据：备份里的真实上屏记录 `choice_log.jsonl`（15,763 条 / 4,723 词），按时间排序模拟 App 学习（bigram +3 / trigram +1 / 每对记最后时间），按时间切 train/test，超参数只在 dev 段上选，test 只报告一次。脚本：`tools/eval_assoc.py`。

对照模型：旧 `predict()`、v3、以及本轮尝试过的变体。

## 三、试过但没采用的方案

| 方案 | 结果 | 结论 |
|---|---|---|
| 多上下文 bigram（prev2/prev3/prev4 加权） | hit@1 4.27%→3.94~4.12% | 上下文越远越吵，放弃 |
| 近期使用衰减（recent window boost） | 无提升 | 放弃 |
| PMI / out-degree 归一 | hit@5 反而降 | 放弃 |
| 逻辑回归学习排序（softmax over pool） | dev 只有 132 个可训练 query，权重乱跳，test hit@1 2.81% | 数据太少，过拟合，放弃 |
| gated fill（证据词优先、高频词只补空位） | hit@5 9.77% < mixed | 补位词太靠后，放弃 |
| **混合池 + 证据门槛（v4）** | hit@1 3.98% / hit@5 9.72% | **采用** |

## 四、v4 打分

候选池 = 有接续证据的词 ∪ 个人高频前 45 词（去同词）。

```
score =
    8  × live_bigram_count × 0.5^(距今天数/14)
  + 3  × min(种子 bigram, 10)
  + 14 × live_trigram_count
  + 10 × min(种子 trigram, 4)
  + 3  × log1p(个人词频)          // 只用于候选池内排序，不额外造词
```

**证据门槛**：一个「有接续证据」的候选都没有时直接返回空（保持原来的「空候选 → 律动」行为，不在每次上屏后硬凑 5 个常用词）。

## 六、代码与开关

- `AssocStore.predictV4(prev1, prev2, max)`：混合池 + 门槛；`topFreq()` 缓存个人高频前 45。
- `ClawImeService.buildAssoc()`：默认 v4；`assoc_v4=false` → v3；`assoc_v3=false` → v2/旧。
- `ClawImeService.ctxCandidates()`（拼音态「上文接得上」的候选）：也用 v4，参数顺序已修（lastWord 才是 prev1）。
- **埋点**：`Dbg.log("assoc show v4=... ctx=前1|前2 -> [候选]")` 写入本机 `claw.log`，用于明天分析真实曝光/点选，不联网。

## 七、本轮试过但没采用的方案（负结果，避免以后重走）

| 方案 | 结果 | 结论 |
|---|---|---|
| 概率式插值 LM（P(w|prev1) 与 P(w|prev2)/unigram 按计数插值，调 k/beta） | hit@1 3.0%、hit@5 7.8%，低于加法打分 | 稀疏计数下归一化反而伤排序 |
| 会话词频加成（最近 200 词重复词 +1.5×log） | hit@5 ±0.3pt，两切分方向不一致 | 不采纳 |
| 双字词偏好 +1 | hit@1 +0.06pt，hit@5 持平 | 不采纳 |
| 种子 bigram 上限 10→20/40 | 全面下降 | 保持 10 |
| 证据词生僻过滤 / 单字通用词过滤 | 过滤单字通用词使 hit@5 -1.6pt | 单字功能词是正确联想，不能砍 |
| 逻辑回归学习排序（softmax over pool） | 可训练 query 仅 132 个，权重乱跳，test hit@1 2.8% | 数据量不够，放弃 |

**经验**：这轮真正的增益来自「候选池覆盖」，不是更复杂的学习器。评测脚本和变体都留在 `tools/eval_assoc.py`，可扩展。

5. 真实反馈闭环：先用埋点收集「曝光 → 点选」，做位置去偏后，再决定 v4 的高频补位权重是否需要按场景下调。
